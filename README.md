# Prachi Singh — Personal Portfolio Website

A modern, premium, responsive personal portfolio built with **React**, **Vite**, **Tailwind CSS**, and **Lucide React**. Engineered with a dark & bright mode purple theme UI, glassmorphic cards, glowing animated accents, interactive project simulations, and full SEO metadata.

---

## 🌟 Highlights & Features

- **💜 Purple Theme UI with Dark & Bright (Light) Mode Toggle**: Effortless instant switching between deep obsidian/violet dark mode and radiant lilac/lavender bright mode with localStorage persistence.
- **🖼️ Profile Showcase**: Displays Prachi's photo with animated glowing aura and an active verification badge referencing the original [Google Drive Asset](https://drive.google.com/file/d/13Ln5CFC3SMq_LyV3Bo5_aSks_AznWtG2/view?usp=sharing).
- **🚀 Featured Projects with Live Links**:
  - **SmartFace — Enterprise AI Employee Attendance Platform**: [Live Demo](https://attendance-seven-green.vercel.app/) | [GitHub](https://github.com/Prachi0216-tech/attendence)
  - **MyRoute — Real-Time Transit & Commute Platform**: [Live Demo](https://myroute-transit.onrender.com/) | [GitHub](https://github.com/Prachi0216-tech/route)
  - **Brand Sentiment Analysis & Web Platform**: [GitHub](https://github.com/Prachi0216-tech/brand-sentiment-analysis)
- **⚡ Interactive Live UI Simulations**:
  - Live WebSocket camera frame and state-machine punch toggle for SmartFace.
  - Interactive Leaflet bus route tracking card with PWA status for MyRoute.
  - Interactive real-time TF-IDF sentiment classifier for Brand Sentiment Analysis.
- **📄 Interactive Resume Modal**: Complete resume viewer with browser-native clean 1-click print / PDF export.
- **📬 Validated Contact Form**: Real-time validation, confetti burst animation, direct mailto fallback, and 1-click copy for phone and email.

## 🚀 Local Development

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Start Development Server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

3. **Build for Production**:
   ```bash
   npm run build
   ```

---

## 🌐 Deploy to Vercel

### Method 1: Using GitHub (Recommended)
1. Push this repository to your GitHub account (`https://github.com/Prachi0216-tech/portfolio`).
2. Log into [Vercel](https://vercel.com).
3. Click **"Add New..."** -> **"Project"** -> Select your portfolio repository.
4. Framework Preset will auto-detect as **Vite**.
5. Click **"Deploy"**. Your portfolio is live with automatic CI/CD!

### Method 2: Using Vercel CLI
```bash
npx vercel login
npx vercel --prod
```
The pre-configured `vercel.json` ensures all SPA client routing and assets work seamlessly out of the box.
